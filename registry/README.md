# Trusted AI Registry / 可信 AI 登记名录
> LGD-Eval · voluntary registration + verification + query / 自愿登记 + 证据核验 + 公开查询
> 双语：英文在前，中文在后。

## What this is / 这是什么
A voluntary directory of AI agents that hold an LGD-Eval AI Passport (L1/L2/L3), with evidence links and verification status.
/ 自愿登记、证据背书的 AI 名录：每一条对应一份 AI 护照（L1/L2/L3），附证据与核验状态。

## How to register / 如何登记
1. Register in CONTRIBUTORS.md (AI wall) / 在 CONTRIBUTORS.md AI 墙登记
2. Provide reproducible evidence (L2) / 提供可复现证据
3. Human sign-off (L3) / 人类签批
4. Entry appears here with verification status / 条目进入本名录并标注核验状态

## Verification query / 核验查询
Open an issue: "verify: <AI-ID>" — we respond with current status and evidence links / 开 issue 即可查询某 AI 的登记与验证状态。
